## Project Description
A Java console application that manages university student records and represents connections between campus locations. The system demonstrates the practical use of linked lists, stacks, queues, trees, hashing, and graphs.

## How to Run

1. Open a terminal or command prompt and navigate to the `src` folder:
   ```bash
   cd src
   ```
2. Compile all the Java files:
   ```bash
   javac *.java
   ```
3. Run the main application:
   ```bash
   java Main
   ```
4. Follow the on-screen console menu (Options 1-16) to navigate the system.
